Proyectos




Gestor de Gastos Personales

Este proyecto es una aplicación web que permite a los usuarios gestionar sus gastos personales de manera eficiente. Los usuarios pueden registrar sus ingresos y gastos, categorizarlos, y generar informes visuales para analizar su situación financiera.


Plataforma de Reservas o Citas

Este proyecto es una aplicación web que permite a los usuarios reservar citas o servicios de manera eficiente. Los usuarios pueden seleccionar el servicio deseado, elegir una fecha y hora disponible, y confirmar su reserva.


SaaS / Dashboard de Gestión (Panel de Control)

Este proyecto es una aplicación web que permite a los usuarios gestionar su negocio de manera eficiente. Los usuarios pueden acceder a un panel de control donde pueden visualizar métricas, gestionar usuarios, y realizar diversas tareas administrativas.
